# PetCare Management System — Firebase Ready

Firebase config is included in `app/google-services.json`.

Package: `com.example.petcare`

Features:
- Firebase Email/Password registration and login
- Firestore user records
- Pet add/list/delete
- Vaccination records
- Vet appointments
- Medicines
- Reminders
- Dashboard and logout

Firebase Console:
1. Enable Authentication > Email/Password.
2. Create Firestore Database.
3. Apply `firestore.rules` (or configure equivalent secure rules).
4. Open this project in Android Studio.
5. Sync Gradle and Run.

Note: Android Studio/Gradle itself is required to build the APK. This ZIP is the source project, not an APK.
